# 🪞 The Anti-Algorithm V2

A stronger, explainable recommendation prototype that deliberately suggests options far outside the user's normal taste.

## Improvements
- Different scores for different results
- Six visible dimensions per category
- Clear explanation of why a result was chosen
- Ranked anti-recommendations
- Taste Shift Tracker
- Cleaner step-by-step interface

## Run
```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```
